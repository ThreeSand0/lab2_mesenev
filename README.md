# Личная страница и 4D-графикатор

Небольшой статический сайт-визитка с встроенным интерактивным 4D-графикатором студента Резникова Тимофея 

## О проекте

Сайт состоит из двух частей:
1. **Визитка:** краткая информация об учёбе в ИМКТ ДВФУ, руководстве отделом в студенческом медиа «Сейчас Объясню» и участии в Академическом хоре ДВФУ.
2. **4D-графикатор:** инструмент для визуализации функций вида z = f(x, y, w) методом гиперплоских сечений.

## Возможности графикатора

* Построение 3D-срезов четырёхмерной поверхности в реальном времени при изменении ползунка координаты `w`.
* Ввод произвольных математических формул (`sin`, `cos`, `tan`, `sqrt`, `abs`, `exp`, `log`, `max`, `min`, степени через `^`).
* Готовые пресеты поверхностей (волны, пульсация, 4D-шар, интерференция).
* Вращение сцены мышью или на сенсорном экране, настройка масштаба и детализации сетки.
* Цветовая карта высоты по оси Z и сортировка полигонов по глубине (алгоритм художника).
